# CLAUDE.md — Портфолио-сайт Кирилла

## О проекте
Личный портфолио-сайт фриланс веб-разработчика (full-stack). Цель — конверсия заказчиков с Kwork, FL.ru и Telegram-сообществ. Аудитория: русскоязычные предприниматели и малый бизнес. Сайт должен продавать услуги, а не просто показывать работы.

## Стек
- Next.js 15 (App Router, `output: 'export'` — полностью статический билд)
- TypeScript (strict)
- Tailwind CSS 4
- Деплой: Cloudflare Pages (статика, без SSR/функций)
- Язык контента: ТОЛЬКО русский. Никакого английского в UI.
- В блоке навыков на сайте строку React оформить как «React / Next.js — Hooks, Router, Context, SSG» (сам сайт — пруф). Tailwind отдельно не выпячивать, это деталь реализации.

## Жёсткие правила работы
1. Одна задача за сессию. Не батчить изменения без явного запроса.
2. После каждого принятого изменения показывать `git log --oneline -3`.
3. Dev-сервер всегда открывать по `127.0.0.1:3000`, НЕ `localhost` (VPN/прокси в браузере).
4. `git push` на GitHub работает только при включённом VPN (DPI провайдера). Перед пушем напомнить включить VPN.
5. Никогда не предлагать кастомный курсор.
6. Не тянуть внешние шрифты с Google Fonts CDN (блокировки/деградация) — только self-hosted через `next/font/local` или `next/font/google` с бандлингом на билде.
7. Никаких тяжёлых WebGL-эффектов поверх реального контента.
8. Перед завершением этапа — прогнать build и проверить, что статический экспорт собирается без ошибок.

## Качество
- Цель: Lighthouse 100/100/100/100 (как у MAISON).
- Семантическая вёрстка, доступность (фокус-стили, контраст, alt).
- Изображения: AVIF/WebP, явные width/height, lazy ниже фолда.
- Никакого шаблонного «AI-дизайна»: без градиентных блобов, стоковых иконок-эмодзи, дефолтного Inter-на-белом.

## Структура MVP
- `/` — главная: хиро, услуги с ценами, превью кейсов, процесс работы, контакты
- `/case/maison` — детальный кейс MAISON (флагман)
- `/case/[slug]` — шаблон под будущие кейсы (дашборд, API, Telegram-бот)
- Контакты: Telegram — основной канал, кнопка-CTA сквозная

## Доступные скиллы

- `codebase-design`, `domain-modeling` — архитектура и доменное моделирование

- `git-guardrails-claude-code` — защита от опасных git-команд
- `postgres-pro` — PostgreSQL
- `claude-api` — справочник по Claude API/Anthropic SDK
